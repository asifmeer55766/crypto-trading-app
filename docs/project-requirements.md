# Project Requirements

## Functional Requirements

- FR-01 User registration
- FR-02 User login/logout
- FR-03 User dashboard
- FR-04 Cryptocurrency market listing
- FR-05 Search and filter coins
- FR-06 Individual coin details
- FR-07 Price charts
- FR-08 Virtual wallet
- FR-09 Buy crypto
- FR-10 Sell crypto
- FR-11 Portfolio management
- FR-12 Profit/loss calculation
- FR-13 Transaction history
- FR-14 Reset virtual account
- FR-15 User profile management
- FR-16 Admin dashboard

## Non-functional requirements

Ye application ki quality aur security define karti hain.

- Passwords securely hashed hon.
- API keys frontend mein expose na hon.
- Users sirf apna portfolio access kar saken.
- Duplicate transactions prevent hon.
- Invalid quantities reject hon.
- API failures gracefully handle hon.
- Database operations reliable hon.
- Mobile responsive interface ho.
- Application reasonable loading time maintain kare.
